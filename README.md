## מטרות
- לספק את תמונת החדשות הכלכלית החשובה בישראל ובעולם.
- להעדיף איכות, חשיבות, אימות והקשר על פני כמות.
- לכתוב תוכן מקורי בעברית ולקשר למקורות.
- להפעיל בהמשך מהדורה יומית אוטונומית באמצעות ChatGPT ו-TinyFish.
